# Scientific Services

This directory contains the scientific specifications for each computational service within the HakaseAI Peptide Discovery Platform.

Each service is responsible for a single scientific capability and produces immutable Evidence Objects. Services are independent, modular, and orchestrated through the Scientific Workflow.

## Services

| Service | Responsibility |
|----------|----------------|
| Physicochemical Service | Sequence characterization and molecular descriptors |
| Structural Biology Service | Structure prediction and peptide-target modeling |
| Functional Analysis Service | Biological activity and target engagement prediction |
| Developability Service | Pharmaceutical developability assessment |
| Safety Service | Toxicity, immunogenicity, and safety assessment |

## Design Principles

- Single Responsibility
- Evidence-Driven Computation
- Immutable Evidence Objects
- Independent Deployment
- Explainable Scientific Predictions
