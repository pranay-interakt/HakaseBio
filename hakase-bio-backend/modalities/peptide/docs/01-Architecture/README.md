# Architecture

This directory contains the foundational architecture documentation for the HakaseAI Peptide Discovery Platform.

These documents define the platform's scientific architecture, workflow, domain model, evidence framework, decision framework, and privacy principles. Together they serve as the primary design reference for all engineering and scientific implementation.

## Documents

| Document | Purpose |
|----------|---------|
| Architecture Specification | Overall system architecture and design philosophy |
| Scientific Workflow Specification | End-to-end execution workflow |
| Domain Model Specification | Canonical platform objects and relationships |
| Evidence Framework Specification | Standardized Evidence Object architecture |
| Decision & Reasoning Framework | Evidence integration and recommendation generation |
| Privacy & Data Governance | Privacy-first architecture and data governance |
