# ── Hakase ADMET engine — REQUIRED for ML provenance ────────────────────────
# The engine itself is vendored in-tree at hakase_admet/ (Chemprop-RDKit
# ensemble + bundled weights); no pip package to install. These are its
# runtime deps. Without them the ai-service silently degrades to heuristics
# while UPSTREAM thinks it's getting ML predictions. The recalibrated L1
# scorecard (l1Scorecard.ts thresholds.json) is tuned to the ML output
# distribution, not the heuristic one — running mismatched is the root cause
# of "every known drug → NO-GO". STRICT_ML=1 in env makes the service refuse
# to start when the engine can't load (see admet_ml.warmup).
