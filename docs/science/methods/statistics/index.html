Statistics methods.

6 methods in this area. Each lists the assumptions it makes and the limits outside which its result is not valid.

stats.assumption_gate · version 1.0.0

Test of Dunnett's assumptions before use: Brown-Forsythe variance homogeneity and Shapiro-Wilk normality of within-group residuals

Assumptions

  • the assumption tests are run at 0.05 unless the protocol states otherwise, independently of the level the comparison itself is judged at
  • Levene's test is centred on the group median (the Brown-Forsythe form)

Limits

  • with small group sizes both tests have little power, so an assumption can fail to be rejected simply because n is small
  • a gate that cannot be evaluated sends the data to the rank-based test, which needs neither assumption, rather than passing by default

References

  • Levene H. Robust tests for equality of variances. In: Olkin I, Ghurye SG, Hoeffding W, Madow WG, Mann HB, eds. Contributions to Probability and Statistics: Essays in Honor of Harold Hotelling. Stanford University Press; 1960:278-292.
  • Brown MB, Forsythe AB. Robust tests for the equality of variances. J Am Stat Assoc. 1974;69(346):364-367. doi.org/10.1080/01621459.1974.10482955
  • Shapiro SS, Wilk MB. An analysis of variance test for normality (complete samples). Biometrika. 1965;52(3-4):591-611. doi.org/10.1093/biomet/52.3-4.591
  • Hamada C. Statistical analysis for toxicity studies. J Toxicol Pathol. 2018;31(1):15-22. doi.org/10.1293/tox.2017-0050

stats.cochran_armitage · version 1.0.0

Cochran-Armitage score test for a linear trend in finding incidence across ordered dose groups

Assumptions

  • dose scores are the group doses unless the protocol states other spacing (e.g. ranks); the score spacing changes the statistic and is recorded
  • the statistic is referred to the standard normal (large-sample approximation)

Limits

  • the normal approximation is unreliable when expected affected or unaffected counts are very small; it is not the exact permutation trend test
  • it does not select a significance level by tumour rarity: the Haseman 1983 rule is a cited decision framework applied against a historical-control context this method is not given
  • statistical significance is not adversity (FDA 2005 glossary, NOAEL)

References

  • Cochran WG. Some methods for strengthening the common chi-square tests. Biometrics. 1954;10(4):417-451. doi.org/10.2307/3001616
  • Armitage P. Tests for linear trends in proportions and frequencies. Biometrics. 1955;11(3):375-386. doi.org/10.2307/3001775

stats.dunn_holm · version 1.0.0

Dunn rank-sum comparison of each dose group with control, with Holm's step-down adjustment

Assumptions

  • observations are ranked across all groups together, so the comparisons form one family
  • the tie correction of Dunn 1964 is applied

Limits

  • Steel's 1959 many-to-one rank test is the exact non-parametric analogue of Dunnett for this design and is not implemented; Dunn with Holm controls the family-wise error rate but is more conservative, so a real effect can be missed
  • the normal approximation to the rank-sum distribution is poor at very small group sizes
  • statistical significance is not adversity

References

  • Dunn OJ. Multiple comparisons using rank sums. Technometrics. 1964;6(3):241-252. doi.org/10.1080/00401706.1964.10490181
  • Holm S. A simple sequentially rejective multiple test procedure. Scand J Stat. 1979;6(2):65-70.
  • Hamada C. Statistical analysis for toxicity studies. J Toxicol Pathol. 2018;31(1):15-22. doi.org/10.1293/tox.2017-0050
  • Steel RGD. A multiple comparison rank sum test: treatments versus control. Biometrics. 1959;15(4):560-572. doi.org/10.2307/2527654

stats.dunnett · version 1.1.0

Dunnett many-to-one comparison of each dose group with control

Assumptions

  • approximately normal residuals within groups
  • homogeneous variances across groups
  • both are tested before this method is used (stats.assumption_gate); where either fails the rank-based comparison is run instead

Limits

  • statistical significance is not adversity; biologically significant effects can be non-significant (FDA 2005 glossary, NOAEL)
  • no data transformation is applied; choosing one is a judgement about the endpoint and is left to the study's statistician

References

  • Dunnett CW. A multiple comparison procedure for comparing several treatments with a control. J Am Stat Assoc. 1955;50(272):1096-1121. doi.org/10.1080/01621459.1955.10501294
  • Jaki T, Hothorn LA. Statistical evaluation of toxicological assays: Dunnett or Williams test - take both. Arch Toxicol. 2013;87(11):1901-1910. doi.org/10.1007/s00204-013-1065-x

stats.fisher_exact · version 1.0.0

Fisher's exact test of a dose group's finding incidence against the concurrent control (2x2 affected/unaffected x group/control)

Assumptions

  • the two margins are treated as the basis of the exact hypergeometric distribution; the test is exact for any cell count, including zeros
  • one-sided 'greater' tests for a higher incidence in the treated group, the direction of toxicological concern, unless two-sided is stated

Limits

  • no multiplicity adjustment across dose groups is applied here; whether and how to correct the family is the study statistician's decision
  • statistical significance is not adversity (FDA 2005 glossary, NOAEL)
  • a dose-response trend is tested by stats.cochran_armitage, not by pairwise comparisons

References

  • Fisher RA. On the interpretation of chi-square from contingency tables, and the calculation of P. J R Stat Soc. 1922;85(1):87-94. doi.org/10.2307/2340521
  • Fisher RA. The logic of inductive inference. J R Stat Soc. 1935;98(1):39-82. doi.org/10.2307/2342435

stats.group_summary · version 1.0.0

Group mean and standard deviation per dose level

Assumptions

None stated.

Limits

  • descriptive only

References

  • OECD. Test No. 408: Repeated Dose 90-Day Oral Toxicity Study in Rodents. OECD Guidelines for the Testing of Chemicals, Section 4. Revised 2018. doi.org/10.1787/9789264070707-en
