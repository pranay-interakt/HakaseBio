13 methods in this area. Each lists the assumptions it makes and the limits outside which its result is not valid.

sim.ames_counts · version 1.0.0

Simulated revertant counts from declared expected values per strain, activation and concentration (exact or Poisson-sampled)

Assumptions

None stated.

Limits

  • for software verification and workflow demonstration only; never admissible as evidence

References
