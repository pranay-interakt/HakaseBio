Historical and virtual controls methods.

1 method in this area. Each lists the assumptions it makes and the limits outside which its result is not valid.

controls.time_forward_certification · version 1.0.0

Time-forward certification of a virtual-control comparison: false-positive rate on held-out control groups and agreement with concurrent controls on treated groups, replayed in archive order

Assumptions

  • each study is scored using only studies earlier in the archive order, as a new study would be
  • the false-positive rate is counted on control groups, which carry no treatment effect by construction; its interval is Clopper-Pearson
  • agreement and sensitivity take the concurrent-control result as the reference

Limits

  • holds for the pack's design space (species, strain, sex, route, regimen, time point) and endpoints only
  • a public pack is not a sponsor's historical controls; the EMA draft opinion expects matched test facility, strain, sex and supplier
